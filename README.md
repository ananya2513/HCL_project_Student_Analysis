**Student Career Success Analysis System**

**Project Overview**

A menu-driven Student Career Success Analysis System developed using Python, Pandas and NumPy. The project analyses student academic performance, technical skills, internships, employability scores and placement statistics using an existing CSV dataset.

**Objectives**

- Load and explore student career success data.
- Calculate overall placement statistics and placement percentages.
- Analyse academic performance, including CGPA, attendance and study hours.
- Perform major-wise placement analysis.
- Compare internship experience with placement outcomes.
- Analyse technical and soft skills of students.
- Calculate average, highest and lowest starting salaries.
- Analyse student employability scores using statistical methods.
- Search individual student records using Student ID.
- Display an overall dataset summary.

**Technologies Used**

- Python
- Pandas
- NumPy
- Google Colab
- GitHub

**Dataset**

Student Career Success Dataset obtained from Kaggle.

The dataset contains 50,000 student records and 29 columns covering academic performance, technical skills, internships, employability and placement information.

**How to Run**

1. Download or clone the project repository.
2. Open the Python notebook in Google Colab.
3. Upload the required "student_career_success_dataset.csv" file.
4. Install Pandas and NumPy if they are not already available.
5. Run the notebook cells.
6. Select an option from the menu to perform the desired analysis.
